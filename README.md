App de previsão do  tempo desenvolvido com HTML, CSS e JS.

# Funcionalidades
Busca de clima por nome da cidade; Exibe temperatura, umidade, velocidade do vento e descreve o céu;
Tratamento de erros para cidade não encontrada; Interface responsiva.

# Tecnologias
Html5, Css3, Js e OpenWeatherMap API

# Como usar
Primeiro crie uma conta na openweathermap.org, copie sua chave API, em "const chave" no 'script.js' substitua a chave pela sua e abra o "index.html" no seu navegador.

# Oq eu aprendi/melhorei
Consumo de API com fetch, funções com async/awai, manipulação de objetos JSON e tratamento de erros com try/catch
